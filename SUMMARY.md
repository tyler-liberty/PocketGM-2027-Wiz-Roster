# PocketGM Pre Draft v6.8 — OLB remap via Madden

ESPN labels almost all linebackers as generic `LB`, which previously mapped everyone to **MLB**.

## Fix
For ESPN LBs (and LB-family PGM cards), set PocketGM position from **Madden 27**:
- `MIKE` → MLB
- `WILL` / `SAM` → OLB
- `LEDG` / `REDG` → DE

## Remaps: **173**
- Teams with 0 OLB before: 24 → after: **0**
